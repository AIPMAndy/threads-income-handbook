03 / RECONCILE THE FUNNEL

示例 A / 专业服务

有技能，但还没有很多粉丝

谁会付钱
面向有社招求职需求的职场人
内容怎么写
分享一次简历问题诊断的匿名方法，而非虚构客户成功案例
卖什么
60 分钟职业诊断 + 交付诊断清单
核算口径
目标用户咨询量 → 合格询盘 → 报价 → 实收 → 总工时

边界：录用由招聘方决定，不能保证 Offer

示例 B / 数字产品

被反复问同一个问题

谁会付钱
第一次经营个人品牌的独立开发者
内容怎么写

卖什么
可编辑模板包 + 示例 + 更新说明
核算口径
样例真实访问 → 意向反馈 → 已付款订单 → 退款/支持工时

边界：免费索取与付费购买要分开统计

示例 C / B2B

高客单但销售周期更长

一次工作流诊断和书面优先级建议
核算口径
合格负责人预约 → 到会 → 方案 → 签约 → 回款

边界：保密数据未经授权不得上传第三方服务
